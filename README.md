# CoinMaster

CoinMaster is a .NET desktop application designed to display various information related to cryptocurrencies.

## 🚀 Features

### Core Functionality
* **Market Overview:** The main page displays the top N cryptocurrencies by popularity.
* **Search:** Features a search capability to find specific currencies by their name or code.
* **Detailed Coin Info:** Provides a dedicated page for each currency detailing its current price, volume, and price change.
* **Market Navigation:** Displays the markets where a specific coin can be purchased, including prices and the ability to go directly to the currency page on the market.

### Additional Features
* **Candlestick Charts:** Implements visual quote charts using Japanese candlesticks for in-depth currency analysis.
* **Currency Converter:** A separate page allowing users to easily convert one cryptocurrency to another.
* **Theming:** Full support for toggling between Light and Dark themes.
* **Localization:** Supports multiple language localizations (English and Ukrainian).
